Política de privacidade

Última atualização: novembro de 2026

A Mota Lanches respeita a sua privacidade. Esta página explica, de forma simples, quais dados pedimos quando você faz um pedido pelo site, para que usamos e quais são os seus direitos, conforme a Lei Geral de Proteção de Dados (LGPD – Lei nº 13.709/2018).

1. Quais dados pedimos

  • Nome e WhatsApp — para identificar e falar com você sobre o pedido;
  • Endereço, bairro e ponto de referência — só quando o pedido é para entrega;
  • Itens do pedido, observações e forma de pagamento (e o valor do troco, se for em dinheiro).

Não pedimos CPF, senha ou dados de cartão. O pagamento por Pix é feito no app do seu banco; o site só mostra o código Pix com o valor do pedido.

2. Para que usamos

  • Preparar, entregar ou separar o seu pedido para retirada;
  • Falar com você pelo WhatsApp sobre o andamento do pedido;
  • Controle interno de vendas da loja (por exemplo, relatórios de pedidos).

Não vendemos nem passamos os seus dados para outras empresas para propaganda.

3. Onde os dados ficam

Os pedidos ficam guardados num banco de dados protegido, que só a equipe da loja acessa com senha. Para facilitar o próximo pedido, o seu próprio celular guarda o seu nome, WhatsApp, endereço, a sacola e a lista "Meus pedidos". Você pode apagar isso limpando os dados do navegador.

4. Por quanto tempo

Guardamos os pedidos pelo tempo necessário para o controle da loja e para cumprir obrigações legais. Depois disso, eles podem ser excluídos.

5. Seus direitos

Você pode pedir, a qualquer momento, para saber quais dados seus temos, corrigir ou apagar os seus dados, quando a lei permitir. É só falar com a gente pelos contatos abaixo.
